# Scale reference

Chassis vehicles use **Crayfish-style scale**: compact and chunky, not real-world size. Measure against these when blocking out in Blockbench.

## Units
- **1 block = 16 Blockbench pixels.** All JSON dimensions are in blocks.
- **Player:** 1.8 blocks tall (28.8 px), 0.6 blocks wide (9.6 px).
- **Textures:** 16x per block, flat vanilla-friendly colours, no gradients.

## Style rules
- Stepped edges instead of angles: roofs, screens and corners step in 1–2 px at a time.
- Wheels tucked into the body with arch trim, never stuck on the outside.
- Thin pillars, big glass.
- Separate bumpers, grille and mirrors so it reads as a vehicle, not a brick.
